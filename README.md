# Notes App

Sistema simples de anotações — teste técnico Pleno.

- **Backend:** Ruby on Rails 8.1 (API-only) + PostgreSQL
- **Frontend:** Vue 3 + Vite + TypeScript + PrimeVue
- **Infra:** Docker Compose

> Documentação completa de execução, arquitetura e decisões técnicas será adicionada ao final da implementação. Este arquivo é um esqueleto inicial.
